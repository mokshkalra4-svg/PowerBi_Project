# 📊 HR Analytics Dashboard (Power BI)

## 📌 Project Overview
This project is an interactive HR Analytics Dashboard built using Microsoft Power BI. It provides insights into employee demographics, attrition, salary distribution, department performance, and workforce trends to support HR decision-making.

---

## 🎯 Objectives
- Analyze employee demographics.
- Monitor employee attrition.
- Track department-wise performance.
- Analyze salary distribution.
- Visualize workforce trends.
- Provide actionable HR insights.

---

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Modeling

---

## 📈 Dashboard Features

### Executive Summary
- Total Employees
- Active Employees
- Attrition Rate
- Average Salary
- Average Age

### Employee Analysis
- Gender Distribution
- Age Groups
- Education Level
- Marital Status

### Department Analysis
- Department-wise Employees
- Department-wise Attrition
- Average Salary by Department

### Performance Analysis
- Performance Rating
- Experience Distribution
- Promotion Analysis

### Salary Analysis
- Salary by Job Role
- Salary by Department
- Salary Distribution
